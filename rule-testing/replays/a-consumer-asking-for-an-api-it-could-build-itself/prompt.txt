## The situation

Compze.Teventive.StateStore's index, which a consumer declares where it composes the store, and resolves from the container:

```csharp
public interface ITaggregateIndex<out TTaggregate, in TKey> where TTaggregate : class, ITaggregate
{
   ///<summary>The taggregates filed under <paramref name="key"/>, in no particular order.</summary>
   IReadOnlyCollection<ITaggregateReference<TTaggregate>> Lookup(TKey key);

   ///<summary>Whether any taggregate is filed under <paramref name="key"/>, as <see cref="Lookup"/> would find it.</summary>
   bool HasAny(TKey key);
}
```

A reference stands for a taggregate across units of work, and is what code holds instead of an instance. Its `Current` gives the taggregate as it is now: inside a unit of work, the unit of work's own copy if it holds one, else the committed instance. Outside a unit of work a lookup returns the array the index keeps for the key, and allocates nothing.

JAStudio reads every index through one class of its own, `NoteIndex`, whose lookup is:

```csharp
public List<TNote> NotesWith(TKey key) => [.. _index.Value.Lookup(key).Select(it => it.Current)];
```
