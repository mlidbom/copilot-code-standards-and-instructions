## Where the work stands

JAStudio's corpus holds the sentences, vocab and kanji that Magnus studies. Sentences get into it by importing Anki notes: JAStudio.Core.Importing turns Anki notes into corpus sentences through an ImportProfile.

You and Magnus are building a reservoir beside the corpus: millions of sentences from shared Anki decks (.apkg packages) and subtitle files. JAStudio doesn't load them, and sentences will later be taken from the reservoir into the corpus.

Last night, on the branch corpus-reservoir, you built the batch command `reservoir keep-decks` (JAStudio.Core.Reservoir.Keeping). It reads an .apkg and writes it into the reservoir's git repository as plain text: the collection database unchanged, a line of JSON per note, and a deck.json that maps the fields. The deck's media go into a media store. The reservoir's SQLite file is built from these files. You tried it on five decks, and all the specifications pass.
