# Provenance

From the Vantage project, May and June 2026. The agents: most likely Opus 4.8, the latest Opus at the time (released
2026-05-28), or else Opus 4.7.

## What is behind it

- **2026-05-31:** a multi-agent review let bare `IntPtr` window handles flow through domain code. The wording then,
  "when a domain type exists, take that", gave no reason to introduce a type. An agent cleared the handles because no
  domain type existed yet, and because wrapping "would be circular".
- **2026-06-02:** "the only code that should deal in IntPtr is the code that directly calls code we do not control"
  was read as leave for the callers of our own wrappers to hold the `IntPtr`. Hence "only in the exact signature an
  external API / ABI / serialization format dictates", and "one line in".
- **It's applied beyond native code.** In JAStudio, November 2026, agents wrapped strings as they arrived in a tool,
  and kept a `bool?` at the storage edge only.

## What looks removable but isn't

- **"The exact signature ... dictates".** Don't go back to "the code that directly calls code we do not control": our
  own wrappers are that.
- **The open list of primitives.** The user's instruction: the rule must not special-case `IntPtr`. It's the worst
  case in a list; add examples to the list, never branch on one type.

## Tried and rejected

- **Wrapping a library type that already says what it is.** A `WindowHandle` wrapper over the `IntPtr` was deleted
  2026-06-04, at the user's request, for Vanara's `HWND`: typed, and already "a window handle". The test is whether the
  wrapper denotes something the existing type doesn't. The concern was never that a library type appears in our code:
  it is conceptual corruption, and `HWND` doesn't corrupt.
- **A paragraph against the reading of 2026-06-02:** "'this code calls a native wrapper, therefore it may deal in the
  `IntPtr`' is that rule turned inside out". Removed 2026-11-14 (JAStudio, Claude Fable 5.2): the paragraph before it
  says the same. It's in the catalog's history, at commit `8bfcfd2`.

## Not tested

Whether that reading comes back without the paragraph.
